## ✦ SELECTED PROJECTS

### 🚗 Smart Parking System

An IoT-based parking management system connecting **ESP32 hardware
with a web application** for real-time parking monitoring and control.

**Built with**

`ESP32` `IR Sensors` `React` `Node.js` `Express` `REST API`

**Highlights**

* Real-time parking slot monitoring
* Sensor-based vehicle detection
* Automatic slot assignment
* Gate control using servo motor
* Web dashboard for parking status
* Hardware-to-backend communication

---

A sales operations platform developed during a **24-hour hackathon**,

**Built with**

`TypeScript` `Web Development` `Backend Systems`

**Focus**

Deal strategy · Scenario exploration · Sales operations
